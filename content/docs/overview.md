## CsvCftとは？
CsvCftは、アセットの日次CSVを共通形式に変換するツールです。


## 変換後CSV
変換後のCSVは、以下の列で構成されます。

- Date: 日付
- Close: 終値, 基準価額
- Dividends: 配当金, 分配金

データは日付の昇順となります。

```csv {filename="変換後CSV"}
Date,Close,Dividends
2026-06-09,10401,120
2026-06-10,10428,0
```

## 変換元CSV
二重引用符が含まれないCSVを変換することができます。

```csv {filename="変換できないCSV"}
日付,基準価額,分配金
2026-09-30,"12,506","1,020"
2026-10-01,"12,573","0"
```

※ CSVの正確性や完全性などはチェックしません。


## 動作環境
- OS: Windows11
- CPU: AMD / Intel
