## データソース
デフォルトの変換定義には、以下のデータソースが存在しています。

| データソース | 概要                         |
| :----------- | :--------------------------- |
| nm           | 野村 AM 投資信託             |
| mb           | 三菱UFJ AM 投資信託          |
| dw           | 大和 AM 投資信託             |
| amv          | アモーヴァ AM 投資信託       |
| one          | AM One 投資信託              |
| mds          | 三井住友DS AM 投資信託       |
| mt           | 三井住友トラスト AM 投資信託 |
| rt           | 楽天投信投資顧問 投資信託    |
| ns           | ニッセイ AM 投資信託         |
| yf           | yfinance                     |


## 定義内容
配当金と分配金を、できるだけ変換後CSVに出力するようにしています。

ただし、分配金再投資後の基準価額だけを出力している定義もあります。

詳細は、変換定義のファイルをご確認ください。
