## 追加と編集
EXEと同じ場所に `cft-def.ini` を作成して、定義を追加したり編集することができます。

定義は「`データソース.項目名=値`」となります。

```
smp.SkipRows=2
smp.Encoding=UTF-8
smp.DateFmt=yyyy-MM-dd
smp.DateCol=日付
smp.CloseCol=基準価額
smp.DivCol=分配金

sp.Encoding=Shift_JIS
sp.DateFmt=yyyy/MM/dd
sp.DateCol=基準日
sp.CloseCol=再投資後基準価額
```

以下に、定義内容の詳細を記載していきます。

### データソース
名前は、データソースフォルダや銘柄フォルダの先頭と一致している必要があります。フォルダと命名規約の詳細は、[CSVの配置]({{< ref "csv-location.md" >}}) に記載しています。上の例だと、`smp` と `sp` がデータソースです。

### SkipRows
変換対象のCSVで、読み飛ばしたい行数を指定します。CSVのヘッダーから読み込む必要があるため、以下の内容を変換したい場合は `1` を指定します。

```
高配当株式ファンド
日付,基準価額,分配金
2026/09/02,10284,0
```

指定がない場合や、整数に変換できない場合は `0` で動作します。

### Encoding
変換元CSVのエンコーディングを指定します。

### DateFmt
変換元CSVの日付形式を指定します。以下のCSVを変換する場合は、`yyyy/MM/dd` を指定します。

```
日付,基準価額,分配金
2026/09/02,10284,0
```

原則として、変換元CSVの日付形式は「年月日」を想定しています。


### DateCol
変換後に、Dateとして出力したい列の名前を指定します。

### CloseCol
変換後に、Closeとして出力したい列の名前を指定します。

### DivCol
変換後に、Dividendsとして出力したい列の名前を指定します。以下の場合、変換後の値は `0` になります。

- 定義や指定がない場合
- 変換対象の値が空文字の場合
- 変換対象の値が `-` の場合

調整後の終値や、分配金再投資後の基準価額などを使う場合、この項目は指定しないことを推奨しています。分析アプリのDkneでは、Dividendsが0でない場合に再投資をするためです。


## コメント・空行
行が `;` で始まる場合、コメントの扱いになります。

```
; コメント
; smp.SkipRows=2
```

コメントと空行は、定義として評価されません。


## エンコーディング
定義ファイルは、「UTF-8」にする必要があります。


## 定義の削除
使わない定義は、削除することができます。例えば、データソース `dl` を使わない場合は、`dl` から始まる行を削除できます。

```
dl.Encoding=UTF-8
dl.DateFmt=yyyy-MM-dd
dl.DateCol=日付
dl.CloseCol=調整後終値
```
