EXEの実行後、画面のメニューからCSVを変換することができます。


## CSV選択
選択したCSVを変換します。CSVの名前は、「`データソース名-商品識別名.csv`」にする必要があります。

``` {filename="名前の例"}
mb-acwi.csv
```

データソース名は、変換定義に存在する名称を使います。[変換定義のサンプル]({{< ref "sample-def.md" >}}) には、データソース名を記載しています。

データソース名は半角英数、商品識別名は半角英数記号を使用することができます。


## 指定銘柄
入力した銘柄のCSVを変換します。

指定する銘柄は、銘柄フォルダの名前と一致している必要があります。

また、銘柄フォルダにCSVを配置しておく必要があります。詳細は、[CSVの配置]({{< ref "csv-location.md" >}}) に記載しています。


## 一括
銘柄フォルダに存在するCSVを全て変換します。

途中でエラーが発生すると、一部のCSVは変換済みで、残りは未変換になることがあります。

エラーを解消して、再度実行することを推奨しています。
