EXEの実行後、画面のメニューからCSVを変換することができます。


## CSV選択
選択したCSVを変換します。CSVの名前は「`データソース-商品識別名.csv`」にする必要があります。

``` {filename="名前の例"}
mb-acwi.csv
```

データソースは、変換定義に存在するものを使います。[変換定義のサンプル]({{< ref "sample-def.md" >}}) には、データソース名を記載しています。

商品識別名は、半角英数と半角記号を使って付けることができます。


## 指定銘柄
入力した銘柄のCSVを変換します。

銘柄のエリアには、半角英数と半角記号が入力できます。

CSVは、銘柄フォルダに配置しておく必要があります。詳細は、[CSVの配置]({{< ref "csv-location.md" >}}) に記載しています。


## 一括
銘柄フォルダに存在するCSVを全て変換します。

途中でエラーが発生すると、一部のCSVは変換済みで、残りは未変換になることがあります。

エラーを解消して、再度実行することを推奨しています。
