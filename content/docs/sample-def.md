## データソース
サンプルの定義には、以下のデータソースが存在しています。

| データソース | 概要                            |
| :----------- | :------------------------------ |
| nm           | 野村 AM 投資信託                |
| mb           | 三菱UFJ AM 投資信託             |
| dw           | 大和 AM 投資信託                |
| amv          | アモーヴァ AM 投資信託          |
| one          | AM One 投資信託                 |
| mds          | 三井住友DS AM 投資信託          |
| mt           | 三井住友トラスト AM 投資信託    |
| rt           | 楽天投信投資顧問 投資信託       |
| ns           | ニッセイ AM 投資信託            |
| yf           | yfinance（日付形式: yyyy-MM-dd）|


## 定義内容
変換後のCSVには、できるだけ配当金と分配金を出力するようにしています。ただし、分配金再投資後の基準価額だけを出力している定義もあります。

詳細は、ファイルの内容をご確認ください。


## 注意事項
- 動作確認は、一部の商品で行っています。
- 配信元のCSV形式が変更になると、エラーが発生します。
